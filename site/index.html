md2office turns a plain Markdown report into a Word document and PDF that match the assessed Aurora security-narratives book — headers with title & classification, wide autofit tables, shaded monospace code, and a static TOC.

Why md2office

Everything the SA&A book build does, in one import — no scripts to copy between repos.

📄

Bundled SSC template

The reference ssc-template-v2.7.dotx ships inside the package, with the pagebreak, TOC, and mermaid Lua filters.

🔖

Header injection

Title and bilingual classification go into every page header and the core document metadata automatically.

📊

Table fixes

Pandoc tables are rewritten to 100% autofit width with explicit borders, so LibreOffice stops crushing them.

⌨️

Code styling

SourceCode and VerbatimChar get Consolas 9pt and light-grey shading, exactly like the assessed build.

🔁

DOCX → PDF

Headless LibreOffice with a fresh per-run profile, so concurrent conversions don't lock each other out.

🩺

Prerequisite doctor

md2office doctor checks pandoc, LibreOffice, python-docx, and the fonts the PDF needs.

How it works

One pipeline: pandoc builds the DOCX against the SSC template, the package post-processes it, LibreOffice renders the PDF.

Quick start

Install, run doctor, convert. That's it.

terminal
# 1. install
pip install md2office

# 2. check prerequisites
md2office doctor

# 3. convert
md2office docx report.md report.docx --classification "Protected A"
md2office pdf  report.md report.pdf

The title defaults to your YAML frontmatter, and the classification to Unclassified | Non classifié.

Options

Everything is exposed on the CLI and through ConvertOptions.

OptionDefaultMeaning
titlefrontmatterDocument title; written into headers + core metadata
classificationUnclassified | Non classifiéSensitivity label in every page header
number_sectionsFalsePass --number-sections to pandoc
code_styleTrueConsolas 9pt + shading on code styles
page_breaks"none""sections" puts each Heading1 on a new page
font"default""arial" switches the document font
mermaid"auto"Render ``` ```mermaid``` blocks (needs mmdc)
keep_docxFalseKeep the intermediate DOCX when producing a PDF

Library

Use it directly from Python — no shell needed.

python
import md2office

md2office.to_docx("report.md", "report.docx",
                  title="My Report", classification="Protected A")
md2office.to_pdf("report.md", "report.pdf")

# fine-grained control
from md2office import ConvertOptions, to_pdf

opts = ConvertOptions(number_sections=True, font="arial",
                           page_breaks="sections")
to_pdf("report.md", "report.pdf", options=opts)
